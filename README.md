# 🚀 Пакеты AmneziaWG (v3.1) для роутеров с прошивкой OpenWrt

Этот репозиторий является форком проекта [Slava-Shchipunov/awg-openwrt], который был глубоко доработан для поддержки актуальных версий протокола и операционной системы.

**⚠️ ВАЖНО:** В данном форке поддержка старых версий OpenWrt (ниже 24.10.2) **прекращена** во избежание конфликтов с устаревшим веб-интерфейсом. Сборки производятся исключительно для современных версий с нативной поддержкой протокола (AWG 2.0 / `luci-proto-amneziawg`).

## 🌟 Главные отличия этого форка:
* **Поддержка AmneziaWG 3.1 и ниже:** Пакеты собираются с поддержкой новых параметров обфускации (например, `HeaderProtectionKey`, диапазоны таймингов `RekeyTimeout = 3-8` и др.).
* **Принудительное обновление (Force Update):** Скрипт установки научился корректно обновлять старые версии пакетов поверх существующих без ошибок "already installed".
* **Улучшенная совместимость:** Скрипт правильно распознает актуальные релизы ветки **24.10.2 и выше** и устанавливает современный интерфейс `luci-proto-amneziawg`.

## 🛠 Автоматическая установка (Рекомендуется)

Если ваш роутер обладает достаточным объемом ROM, воспользуйтесь этим скриптом. **Вам не нужно ничего выбирать вручную!** Скрипт сам определит архитектуру вашего процессора и версию установленной прошивки OpenWrt. 

Если для вашей версии прошивки уже есть собранные пакеты в этом репозитории (см. список «Готовые релизы» выше), скрипт автоматически скачает нужные файлы и предложит настроить интерфейс.

Подключитесь к роутеру по SSH и выполните команду для скачивания и запуска скрипта:

```bash
wget -O amneziawg-install.sh [https://raw.githubusercontent.com/tsynzyrenko/awg-openwrt/master/amneziawg-install.sh](https://raw.githubusercontent.com/tsynzyrenko/awg-openwrt/master/amneziawg-install.sh) && sh amneziawg-install.sh
```

**Тихий режим (только скачивание и обновление пакетов):**
Если вам не нужно, чтобы скрипт задавал вопросы и настраивал интерфейс (например, вы хотите настроить всё сами или через Podkop), используйте ключ `-n`:

```bash
wget -O amneziawg-install.sh [https://raw.githubusercontent.com/tsynzyrenko/awg-openwrt/master/amneziawg-install.sh](https://raw.githubusercontent.com/tsynzyrenko/awg-openwrt/master/amneziawg-install.sh) && sh amneziawg-install.sh -n
```
